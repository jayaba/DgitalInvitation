Put your background music file in this folder.

1. Use a song you own or are licensed to use (or a royalty-free track).
2. Name it:  wedding-song.mp3
3. Keep it small so it loads quickly on mobile data:
   an MP3 at 96-128 kbps, ideally under 3 MB.

To use a different file name, change "music.file" in src/config/wedding.js.
To remove the music button completely, set "music.enabled" to false there.
